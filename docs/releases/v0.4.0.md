# v0.4.0 · Rust 原生版

CLI、扫描、终端界面、暂存区、会话操作和本地 MCP 迁移到 Rust。发布包为原生可执行文件，运行时不需要 Python；原 Python 源码保留用于兼容性对照。

- 进入总览或工作目录时立即显示小猫 loading，后台扫描完成前不开放清理；区分扫描失败、仍在扫描和扫描完成后没有数据。
- 保留多语言项目产物、活动信息、硬链接去重、macOS APFS 共享空间与释放区间、Agent 缓存和版本、Skill / MCP / Plugin 检查。
- 暂存、恢复和永久清除支持旧版批次；恢复遇到新文件不覆盖。执行前重新检查策略、路径、目录身份、引用和运行状态。
- 附加 Git 工作树通过 Git 删除；符合条件的独立仓库可移入 macOS 废纸篓。未提交改动、未保存的提交、活动引用和未知状态仍保留。
- Codex 会话归档、删除使用本机 Codex 原生命令，并检查执行后的状态。无法确认结果时停止后续操作。
- MCP 默认 8 个只读工具，`--allow-stage` 额外开放 4 个暂存 / 恢复工具；没有永久删除接口。
- 离线 HTML 报告、只读 JSON 快照和会话默认阈值设置继续可用。
- `--build-info` 返回版本、目标平台、编译器和源码 SHA-256，发布包附有相同的构建信息。

终端中的确认词：暂存 `STAGE`，恢复 `RESTORE`，归档 `ARCHIVE`，永久清除 / 工作树删除 `DELETE`，移入废纸篓 `TRASH`。按 Enter 执行，Esc 取消。暂存和移入废纸篓均不立即释放空间。

Windows 保持只读盘点，使用系统 API 读取文件分配量，不跟随 junction 等重解析点。正式发布流程在五个系统 / 架构上分别构建、测试和打包。

迁移对照与本机验收记录见 [Rust 迁移记录](../rust-migration.md)。
