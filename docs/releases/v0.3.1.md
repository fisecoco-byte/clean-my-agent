# Clean My Agent 0.3.1

终端里的 Agent 存储盘点与清理工具，安装包自带运行环境。

## 本次更新

- 修复确认弹窗的键盘操作与焦点提示：`Enter` 确认，`Esc` 取消，左右键或 `Tab` 切换按钮。
- 修复 Windows 目录遍历中的文件身份判断与中文输出编码，避免占用漏计和帮助命令报错。
- 产物列表支持空格勾选，`t` 展示待暂存清单；`v` 直接打开暂存区。
- 暂存区按条目勾选，`d` 删除、`r` 恢复。同一批次未勾选的条目保留；永久删除须输入 `DELETE` 后确认。
- 工作树支持详情、产物清理和 Git 原生删除；执行前检查未提交改动、运行状态、引用与受保护文件。
- 包含多语言项目产物、Agent 缓存与旧版本盘点，以及 MCP 和 Agent Skill 接入说明。

## 安装或更新

macOS / Linux / Ubuntu：

```sh
curl -fsSL https://raw.githubusercontent.com/fisecoco-byte/clean-my-agent/main/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/fisecoco-byte/clean-my-agent/main/install.ps1 | iex
```

随后运行 `clean-my-agent --version`，应显示 `clean-my-agent 0.3.1`。首次安装后，macOS / Linux 重新打开终端使 PATH 生效。

## 安装包

提供 macOS ARM64 / Intel、Linux ARM64 / x64、Windows x64 五个平台安装包，附带 `SHA256SUMS`。Linux 包要求 glibc 2.35+（Ubuntu 22.04+）；Windows ARM64 和 Alpine / musl 暂无原生包。

Windows 当前提供只读盘点，不开放暂存、恢复或删除。macOS / Linux 支持清理流程，依赖检查需本机 Git 和 lsof。暂存不释放空间；永久清除不可恢复。安装包尚未进行 Apple 公证或 Windows 代码签名。
