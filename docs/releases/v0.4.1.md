# v0.4.1 · Rust 原生版与工作目录清理

本次正式发布包含从 v0.3.1 以来的 Rust 迁移、扫描改进和工作目录清理修复。CLI、扫描、终端界面、暂存区、会话操作和本地 MCP 均由 Rust 原生程序运行，不再依赖 Python 运行时。原 Python 源码保留用于兼容性对照。

## 扫描与界面

- 进入总览或工作目录时立即显示小猫 loading，展示耗时与可用进度。后台扫描完成前不开放清理；扫描失败、扫描中和完成后无数据分别提示。
- 修复工作目录页 Space 勾选无响应的问题。增加勾选框，支持多选、全选和取消；移动光标、排序时保留勾选。
- 底部固定显示 `t 清理产物` 与 `d 清理整个目录`。`t` 打开所选目录的产物清单；勾选产物后再次按 `t` 核对暂存。
- `d` 优先核对勾选项，未勾选才使用光标目录；每次仅核对一个完整目录，多选时明确提示。保留项说明原因。
- 保留多语言产物、活动信息、硬链接去重、macOS APFS 共享空间与释放区间、Agent 缓存和版本、Skill / MCP / Plugin 盘点。

## 暂存与清理

- 暂存、恢复和永久清除兼容旧版批次。执行前重新核实策略、路径、目录身份、引用和运行状态。
- **暂存会移动文件，释放 0 B**：在同一文件系统内移入 `${XDG_STATE_HOME:-~/.local/state}/clean-my-agent/<批次>`，不压缩、不自动过期。项目依赖暂存后需要恢复或重新安装。
- 恢复不覆盖原路径的新文件，冲突项保留在暂存区。清除仅处理选中的条目，未选条目保留。
- 附加 Git 工作树通过 Git 删除；符合条件的独立仓库可移入 macOS 系统废纸篓。未提交改动、未推送提交、活动引用和未知状态仍保留。
- Codex 会话操作使用原生命令并验证结果；Claude 会话只读。MCP 默认 8 个只读工具，`--allow-stage` 额外开放 4 个暂存 / 恢复工具，没有永久删除接口。

确认词：暂存 `STAGE`、恢复 `RESTORE`、归档 `ARCHIVE`、永久清除 / 工作树删除 `DELETE`、移入废纸篓 `TRASH`。按 Enter 执行，Esc 取消。移入废纸篓也不会立即释放空间。

## 安装与兼容性

- 提供 macOS Apple Silicon / Intel、Linux ARM64 / x64、Windows x64 共五个原生安装包；使用 README 中同一安装命令即可更新。
- Windows 保持只读盘点与 MCP，使用系统 API 读取文件分配量，不跟随 junction 等重解析点。
- 每个平台独立构建、运行测试、检查可执行文件；全部通过后发布带 SHA-256 校验的安装包，并验证公开在线安装入口。
- `clean-my-agent --build-info` 显示版本、提交、目标平台、编译器和源码摘要；包内附带 `BUILD_INFO.json`、中英文 README 和使用手册。
- 中英文 README 更新为 Rust 版真实终端截图，补充工作目录勾选、清理入口、暂存位置与恢复说明。

## English

This release moves the CLI, scanner, terminal interface and local MCP server to native Rust executables. It adds immediate scan feedback, fixes workspace selection, and exposes persistent artifact and whole-directory cleanup actions. Staging remains recoverable and frees no space; restoration never overwrites new files. Eligible standalone repositories on macOS can move to the system Trash. Windows remains read-only. Re-run the README installer to update, and check `clean-my-agent --version` and `--build-info`.
