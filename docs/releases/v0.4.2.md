# v0.4.2 · 扫描与复核提速

本次发布只减少重复工作，不改变清理结论：完整依赖报告在真实主目录上从约 459 秒降到约 83–100 秒，`--quick` 从约 63 秒降到约 32 秒，批量暂存从约 1.33 秒降到约 0.16 秒。实测条件与可复现脚本见 [扫描性能](../scan-performance.md)。

## 扫描

- 数据目录和 Git 登记的关联工作树改为单遍遍历，测量后的复核只做不用打开目录的检查。
- 只找目录和链接的遍历直接使用目录项自带的类型，文件系统不提供类型时才逐项查询；目录仍以不跟随链接的方式打开，打开后再确认。
- 同一份报告内按目录缓存所属仓库，每个仓库只读取一次跟踪文件清单，并用一次批量查询判断被忽略的产物；特殊文件名或结果不完整时回退到逐项查询。
- 已完整遍历的工作树内部的关联工作树不再重复遍历。
- 等待子进程改为阻塞在输出管道上，取消最迟约 20 毫秒被发现。
- macOS 上使用 `getattrlistbulk` 批量读取目录项；产物测量按目录分发到受控工作线程，默认 4 路，其它平台 1 路，`CLEAN_MY_AGENT_SCAN_WORKERS`（1–8）可覆盖。
- 完整文件盘点的折叠目录改为进程内统计，不再调用系统 `du`；口径与 `du -k -s -x` 一致（分配块、硬链接去重、不跨挂载卷），无法完整读取的目录报告为部分占用。
- `deps --timings` 在标准错误输出各阶段耗时和次数，报告内容不变。

## 操作与界面

- 同一 Agent 的选中产物共用一次批量预检查，不再为每项生成完整报告；移动前 30 秒内的引用复核结果可复用（临时清除 10 秒），超时重新核对。每项移动前仍单独比较目录身份、变更标记和内容摘要，复核未核实或发现新增引用时继续保留。
- 暂存、恢复、永久清除和整树删除成功后按操作返回的路径更新当前列表，不再整页重扫：未移动的行保留上次核查结论。结果不确定、没有路径、会话操作和返回总览时才完整重扫；取消确认不触发重扫。
- 仅浏览子页面后返回总览，直接恢复已完成的结果和光标位置；按 `r`、切换 Agent 或执行文件变更后重新统计。
- 错误按目标隔离：单个目录或目标失败不影响其它项，也不会被当作成功。

## 安装与兼容性

- 提供 macOS Apple Silicon / Intel、Linux ARM64 / x64、Windows x64 共五个原生安装包；使用 README 中同一安装命令即可更新。
- Linux 与非 macOS 平台保持逐项元数据查询，相关耗时未在本机测量；Windows 仍为只读盘点。
- 每个平台独立构建、运行测试和检查可执行文件；全部通过后发布带 SHA-256 校验的安装包。

## English

This release removes duplicated work in scanning and review without changing cleanup decisions: a full dependency report on a real home directory drops from about 459 s to about 83–100 s, `--quick` from about 63 s to about 32 s, and batch staging from about 1.33 s to about 0.16 s. Source trees and Git-registered linked worktrees are now walked once, relative repositories are cached per directory, one batched Git query decides ignored artifacts, and macOS reads directory entries with `getattrlistbulk`. Artifact measurement runs on bounded worker threads (4 by default on macOS, 1 elsewhere). Folded directories are totalled in-process instead of shelling out to `du`. Selected artifacts share one batch precheck; reference reviews are reused for 30 seconds (10 for purge) while every move still compares identity, stamps and a content digest. Successful file operations update the visible list in place, and returning to the overview restores completed results until `r` or a file operation invalidates them.

Re-run the README installer to update, and check `clean-my-agent --version` and `--build-info`.
