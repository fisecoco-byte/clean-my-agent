# Clean My Agent 0.3.2

## 本次更新

- 产物列表顶部提供全选 / 取消全选按钮，支持 `a` / `Ctrl+A`，包含当前筛选下需要滚动查看的全部候选。
- 启动及会话、资源等子页面扫描使用胖英短拿放大镜翻书的 ascii.rest 动画，下面仅保留耗时和真实数量进度；小窗口自动切换单行样式，完成或失败后停止。
- 工作树、工作目录和会话增加高 / 中 / 低 / 极低活跃度，对应不足 5 天、5–9 天、10–14 天、15 天及以上；缺少记录或读取不完整时显示未知。
- 工作树和会话默认把最久未活动的项排在前面，按 `s` 切换活跃度方向或占用大小；产物页也可按所属工作目录的活跃度排序。
- 排序保留勾选对象和当前行，详情显示活动依据和时间；JSON / MCP 同步提供活跃度字段。
- 受管区域中的非 Git 项目目录也能查看占用、活跃度和产物。
- 工作树 / 依赖页首次发现目录前显示 loading，发现目录后展示列表并后台测量；扫描结束后才显示真实空状态。显示采集时间，支持 `r` 刷新和本次运行内的报告复用，操作后失效。
- 统计工作树时复用本次产物测量的文件属性，保留硬链接去重；批量检查工作树引用，并提供可选的 1–4 路扫描并发，默认单路。基准与适用范围见[扫描性能说明](../scan-performance.md)。

活跃度按可见记录估算，不代表每日使用或允许删除；现有暂存恢复、原生删除、运行状态及引用保护规则保持有效。
